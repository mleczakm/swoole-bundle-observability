# Changelog

## 0.1.4 - 2026-09-09

- Limit Composer distribution archives to runtime and user-facing files.
- Normalize line endings for source and package metadata.

## 0.1.0 - 2026-09-08

- Add `/proc` process, RSS, file-descriptor, and TCP telemetry.
- Add process-count, memory-usage, and external HTTP health checks.
- Add an immediately flushed Sentry Trace Metrics recorder.
- Add configurable health thresholds through a Symfony bundle extension.
